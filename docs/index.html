Blog Application

A full-stack blog platform built with React and Express

About the Project

Blog App is a lightweight blogging platform that allows users to create, browse, and read blog posts. The application is built with a modern stack: a React single-page application on the frontend communicating with an Express REST API on the backend.

Posts are composed with a simple title and article body, stored on the server, and displayed in a clean reading experience. The focus is on simplicity and clarity—no accounts, no comments, just writing and reading.

Architecture

React Frontend

Vite · SPA · Port 5173

→

Express API

REST · JSON · Port 3000

→

Data Store

In-memory storage

The frontend makes HTTP requests to the backend API to fetch and create posts. All communication happens over JSON. The backend stores posts in memory (no external database required for development).

Features

Create Posts

Write blog posts with a title and rich article content using a clean editor interface.

Browse Posts

View a list of all published posts on the home page, sorted by most recent.

Read Articles

Click any post to open the full article in a distraction-free reading view.

REST API

A clean JSON API that can be consumed by any client, not just the included frontend.

Responsive Design

The frontend works seamlessly on desktop, tablet, and mobile devices.

Zero Config

No database setup required. Install dependencies and start building immediately.

Quick Start

Get up and running in under a minute:

# Start the backend
cd backend
npm install
npm start

# In a new terminal, start the frontend
cd frontend
npm install
npm run dev

Then open http://localhost:5173 in your browser. See the Setup Guide for detailed instructions.
