Setup Guide

Get the blog application running locally

Prerequisites

  • Node.js — version 18 or later (node -v to check)
  • npm — included with Node.js (version 9+ recommended)
  • A modern web browser (Chrome, Firefox, Safari, Edge)
  • A terminal / command-line interface

Tip: If you don't have Node.js installed, download it from https://nodejs.org. The LTS version is recommended.

Project Structure

blog-app/
  backend/          # Express API server
    package.json
    server.js
  frontend/         # React SPA (Vite)
    package.json
    src/
    index.html
  docs/             # This documentation site

1. Clone the Repository

git clone <repository-url>
cd blog-app

2. Start the Backend

The backend is an Express server that provides the REST API.

  1. Navigate to the backend directory 
    cd backend
  2. Install dependencies 
    npm install
  3. Start the server 
    npm start

    The API will be available at http://localhost:3000.

Note: The backend uses in-memory storage by default. All data is reset when the server restarts.

3. Start the Frontend

The frontend is a React application built with Vite.

  1. Open a new terminal and navigate to the frontend directory 
    cd frontend
  2. Install dependencies 
    npm install
  3. Start the development server 
    npm run dev

    The app will be available at http://localhost:5173.

4. Verify Everything Works

  1. Check the API — open http://localhost:3000/api/posts in your browser. You should see an empty JSON array: []
  2. Check the frontend — open http://localhost:5173. You should see the blog home page.
  3. Create a test post — use the "New Post" button to create a post and verify it appears in the list.

Troubleshooting

Port already in use

If port 3000 or 5173 is already in use, you'll see an EADDRINUSE error. Stop the other process using that port, or configure an alternative port.

CORS errors in the browser console

The backend includes CORS middleware that allows requests from the frontend's development server. If you're running the frontend on a non-default port, ensure the backend's CORS configuration includes that origin.

npm install fails

Make sure you're using Node.js 18 or later. Delete node_modules and package-lock.json, then run npm install again.
