API Reference

RESTful endpoints for managing blog posts

The API runs at http://localhost:3000 by default. All request and response bodies use application/json.

Base URL

http://localhost:3000/api

Endpoints

GET /api/posts

Retrieve a list of all blog posts.

Response

200 OK

[
  {
    "id": "1",
    "title": "My First Post",
    "content": "This is the full article content...",
    "createdAt": "2026-03-27T10:30:00.000Z"
  },
  {
    "id": "2",
    "title": "Another Post",
    "content": "More content here...",
    "createdAt": "2026-03-27T12:00:00.000Z"
  }
]

Error Responses

500 Internal Server Error — Server failed to retrieve posts.

{
  "error": "Failed to retrieve posts"
}
GET /api/posts/:id

Retrieve a single blog post by its ID.

URL Parameters

Parameter Type Description
id string The unique identifier of the post

Response

200 OK

{
  "id": "1",
  "title": "My First Post",
  "content": "This is the full article content...",
  "createdAt": "2026-03-27T10:30:00.000Z"
}

Error Responses

404 Not Found — No post exists with the given ID.

{
  "error": "Post not found"
}
POST /api/posts

Create a new blog post.

Request Body

Field Type Required Description
title string Yes The title of the blog post
content string Yes The full article content

Example Request

POST /api/posts
Content-Type: application/json

{
  "title": "My New Blog Post",
  "content": "This is the article body with all the details..."
}

Response

201 Created

{
  "id": "3",
  "title": "My New Blog Post",
  "content": "This is the article body with all the details...",
  "createdAt": "2026-03-27T14:15:00.000Z"
}

Error Responses

400 Bad Request — Missing required fields.

{
  "error": "Title and content are required"
}

Common Headers

Header Value Required
Content-Type application/json For POST requests
Accept application/json Recommended

Status Codes

Code Meaning
200 Request succeeded
201 Resource created successfully
400 Bad request (missing or invalid fields)
404 Resource not found
500 Internal server error
